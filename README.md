# IP-SAKTI Sahayak

A multilingual, RAG-based AI assistant for Intellectual Property and regulatory guidance in Ayurveda.

## Architecture Stack
- Frontend: React / Vite / Tailwind (Zoho Catalyst Static Hosting)
- Backend: FastAPI / Pydantic (Zoho Catalyst AppSail)
- Database: Qdrant (Vector) / Supabase (Storage)
- LLM Gateway: Groq, Gemini, OpenRouter
- Multilingual: Bhashini API
