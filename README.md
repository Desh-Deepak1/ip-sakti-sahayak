## 🚀 Overview
**IP-SAKTI Sahayak** is a cutting-edge RAG (Retrieval-Augmented Generation) powered legal intelligence engine designed specifically for Intellectual Property (IP) analysis and Ayurveda patent/prior-art evaluation. It bridges the gap between complex statutory laws and modern AI, providing instant, highly accurate legal assessments tailored for both Indian and International jurisdictions.

---

## ✨ Key Features
* **AI-Powered Legal RAG Pipeline:** Retrieves context-aware evidence and statutory provisions using FastEmbed and Qdrant vector database.
* **Dual Jurisdiction Support:** Seamlessly switch between **Indian** and **International** IP frameworks.
* **Secure Authentication:** Robust user session management and profile security powered by **Supabase Auth**.
* **Chat History Persistence:** Chronological retrieval of past legal queries with instant single-click session loading.
* **Modern Sleek UI:** Built with React, Vite, and Tailwind CSS featuring a tech-grid background, smooth transitions, and clean markdown rendering.

---

## 🛠️ Tech Stack

### **Frontend**
* **React.js** (Vite)
* **Tailwind CSS** (Styling & responsive layout)
* **Supabase JS Client** (Authentication & Session handling)

### **Backend**
* **FastAPI** (High-performance async Python framework)
* **Groq API / LLM Gateway** (Fast inference for legal drafting)
* **Qdrant Client & FastEmbed** (Vector search & semantic retrieval)
* **PyMuPDF & Pytesseract** (Document parsing & OCR support)
